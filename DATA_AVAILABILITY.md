# Data Availability

This repository is [`time-cat/MASModel`](https://github.com/time-cat/MASModel). The tables below describe the data that is currently checked in, the files expected by the Hydra configurations, and the upstream data that must be obtained separately.

The code currently reports version `0.1.0` in `pyproject.toml` and targets Python 3.11 (`.python-version`).

## Synthetic DAG data and generation

The synthetic DAG benchmark is part of the current experiment suite rather than an external benchmark. The checked-in files are:

- `datasets/synthetic_dag_240.json`: the general 240-instance corpus used by the default `synthetic-dag` config.
- `datasets/threshold_families/`: threshold families generated by `scripts/generate_threshold_families.py` (each JSON family contains 200 instances and records its budget distribution in metadata).
- `datasets/threshold_families_structure/threshold-chain.json`, `threshold-wide.json`, and `threshold-balanced.json`: 200 medium-difficulty instances per structural family, used by the structure ablations in `bash/`.

The generators enforce at least 200 instances per corpus. To regenerate the default corpus with its recorded seed:

```bash
python scripts/generate_synthetic_dag.py \
  --num-instances 240 \
  --seed 20260908 \
  --output datasets/synthetic_dag_240.json
```

To regenerate the three structure families and their manifest:

```bash
python scripts/generate_threshold_families.py \
  --output-dir datasets/threshold_families_structure \
  --num-instances 200 \
  --seed 20260910
```

A task's structural lower bound is `number of nodes + 1`: one inspection per node plus one final submission. The metadata records this as `theoretical_min_budget`; it is not an observed model trajectory.

## Acquisition and licensing

- PlanCraft and BrowseComp-Plus data are included in the checkout in the files listed above. Preserve the upstream licenses and attribution when redistributing a derived copy.
- Synthetic DAG data are generated by this repository and are covered by the repository license.
- SWE-bench Verified and Terminal-Bench must be obtained from their respective upstream sources. Their Docker images are pulled by the environments at run time.
- Finance-Agent and WorkBench raw upstream repositories are not redistributed. Use the setup scripts to obtain and normalize them; consult each upstream repository for its license.

Do not commit API keys, upstream checkouts, Docker credentials, or generated experiment outputs. The repository `.gitignore` excludes `.env`, `third_party/`, caches, and `exp_outputs/`.
